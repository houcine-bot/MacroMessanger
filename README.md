# AutoResponder Clone

تطبيق أندرويد بيعمل رد تلقائي على رسائل فيسبوك ماسنجر، مبني بـ Kotlin + Jetpack Compose.

## المميزات
- قواعد حسب الشخص (رد مختلف لكل شخص أو رد عام "*")
- رد ثابت أو رد ذكي عن طريق Claude API
- جدولة أوقات التفعيل (مثلاً من 9 الصبح لـ 5 العصر بس)
- تخزين محلي بـ Room Database

## ⚠️ تحذير مهم
الطريقة دي بتعتمد على NotificationListenerService + AccessibilityService،
وده معناه إن التطبيق بيقرا إشعارات ماسنجر ويحاكي الضغط على الشاشة بنفسه.
ده **مش رسمي من فيسبوك/ميتا**، واستخدامه ممكن يعرض حسابك للحظر لو
فيسبوك اكتشف نمط رسائل غير طبيعي (رد فوري جدًا، نفس النص كل مرة...).
استخدمه على مسؤوليتك، ولحسابك الشخصي بس زي ما اتفقنا.

## إزاي تبني الـ APK من غير Android Studio (وأنت شغال VSCode)

المشروع فيه GitHub Actions workflow بيبني الـ APK تلقائيًا. الخطوات:

1. اعمل حساب على GitHub لو معندكش (مجاني): https://github.com/signup
2. اعمل repository جديد (مثلاً اسمه `autoresponder-clone`)
3. من جهازك، في VSCode terminal، جوه فولدر المشروع نفذ:
   ```bash
   git init
   git add .
   git commit -m "أول نسخة من المشروع"
   git branch -M main
   git remote add origin https://github.com/USERNAME/autoresponder-clone.git
   git push -u origin main
   ```
   (غيّر USERNAME باسم حسابك على GitHub)
4. روح على صفحة الـ repo بتاعك على GitHub → تبويب **Actions**
5. هتلاقي الـ workflow اسمه "Build APK" شغال تلقائي (بياخد حوالي 3-5 دقايق)
6. لما يخلص، ادخل على الـ run اللي خلص، هتلاقي تحت في **Artifacts**
   ملف اسمه `app-debug-apk` — نزّله، فكه (zip)، هتلاقي جواه `app-debug.apk`
7. انقل الملف لموبايلك ونصّبه (لازم تفعّل "تثبيت من مصادر غير معروفة" في إعدادات الأندرويد)

## بعد التنصيب على الموبايل
1. افتح التطبيق
2. دوس على "فعّل صلاحية قراءة الإشعارات" وفعّلها للتطبيق من الإعدادات
3. دوس على "فعّل خدمة Accessibility" وفعّلها برضه
4. (اختياري) حط مفتاح Claude API لو عايز رد ذكي
5. ضيف القواعد اللي عايزها بالـ "+"

## ملحوظة عن استقرار الـ Accessibility Service
عناصر واجهة ماسنجر (زرار الإرسال، حقل الكتابة) ممكن تتغير مع تحديثات
التطبيق، فلو الرد بطل يشتغل بعد تحديث ماسنجر، هتحتاج تراجع
`ReplyAccessibilityService.kt` وتظبط طريقة البحث عن العناصر.
